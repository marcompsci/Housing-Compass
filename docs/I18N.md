# Languages

- Trust-critical domain text (categories, trust levels and explainers, price basis) lives in `packages/core/src/i18n.ts`, so every screen and the server share one wording.
- UI strings live in `apps/mobile/src/i18n/strings.ts`. A test fails if any key or `{placeholder}` is missing in a language.
- The device language is picked automatically. Users can switch in Help → Language / Idioma.
- **Spanish was written in-house and must be reviewed by a native speaker before launch.** Its safety sentences ("not a finding of fraud", "never send money") are locked by tests.
- Not yet translated: filters, account, review, affordability and the message checker. Next languages: Chinese (Traditional), Vietnamese, Tagalog.
