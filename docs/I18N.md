# Languages

- Trust-critical domain text (categories, trust levels and explainers, price basis) lives in `packages/core/src/i18n.ts`, so every screen and the server share one wording.
- UI strings live in `apps/mobile/src/i18n/strings.ts`. A test fails if any key or `{placeholder}` is missing in a language.
- The device language is picked automatically. Users can switch in Help → Language / Idioma / 语言, and the choice is remembered on the device.
- **Spanish and Simplified Chinese were written in-house and must be reviewed by native speakers before launch.** Their safety sentences ("not a finding of fraud", "never send money") are locked by tests. Non-English screens show a note that English is the official version.
- Translated (v0.14): Explore, listing details, Help & safety, onboarding, alert settings, move-in savings, travel and sharing.
- Not yet translated: filters, account, review tools, the message checker and checklists (checklists come from `packages/core` in English). Next languages: Chinese (Traditional), Korean, Armenian, Tagalog, Vietnamese.
